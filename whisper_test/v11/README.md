# v11 — GigaAM v3 (`v3_e2e_rnnt`)

## Цель

Проверить, улучшает ли локальная русскоязычная модель GigaAM v3 распознавание
сложной записи лекции относительно предыдущих экспериментов Whisper и Qwen3-ASR.

## Набор аудио

Сравниваются исходный фрагмент и пять наиболее сильных вариантов из прошлых
экспериментов:

1. `chunk_0049_original.wav` — исходный фрагмент;
2. `chunk_0049_target_voice_focus.wav` — лучший результат Whisper medium;
3. `chunk_0049_target_from_13s.wav`;
4. `chunk_0049_target_strong_denoise.wav`;
5. `chunk_0049_lr_60_40.wav` — stereo mix из v7;
6. `chunk_0049_direct_mid.wav` — прямое извлечение из исходного видео.

## Настройки

- бэкенд: `gigaam`;
- модель: `v3_e2e_rnnt`;
- устройство: CPU;
- Silero VAD: threshold `0.5`, min speech `100 ms`, min silence `500 ms`,
  padding `200 ms`;
- после VAD аудио делится на части максимум по 24 секунды.

Последнее ограничение необходимо: официальный короткий метод GigaAM
`transcribe()` принимает WAV длительностью менее 25 секунд. Разбиение не
перекодирует и не ресемплирует уже подготовленный сигнал.

## Артефакты

- `gigaam_v3_comparison.csv` — WER/CER и транскрипции;
- `gigaam_v3_comparison_details.txt` — эталон и выравнивания ошибок.

## Результат

Лучшим для GigaAM оказался `chunk_0049_target_strong_denoise.wav`:
WER **37.04%**, CER **26.06%**. Это лучше остальных вариантов внутри v11,
но хуже лучшего исторического результата Whisper medium на
`target_voice_focus` (WER 27.78%, CER 16.94%).

GigaAM корректно распознала начало целевой фразы как «неявное
преобразование», но во всех вариантах, кроме `lr_60_40`, потеряла или
исказила слово «типов»; `lr_60_40` распознал его полностью, но общий
WER этого варианта составил 44.44%.
