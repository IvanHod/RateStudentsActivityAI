Эксперимент v1

Цель: сравнить варианты очистки одного фрагмента лекции по качеству
распознавания Whisper относительно заданного эталонного текста.

Условия: OpenAI Whisper medium, язык ru, beam_size=5, фрагмент 0 с — конец
файла. Метрики: WER и CER. Подробные результаты: ../whisper_comparison_details.txt.

Важное ограничение: использовался initial_prompt
«Лекция по предмету “Алгоритмы и структуры данных”». Whisper многократно
воспроизводил эту фразу в распознанном тексте. Поэтому результаты вариантов,
где она повторяется, нельзя использовать для честной оценки шумоподавления.

Наблюдения:
- target_continuous формально лучший: WER 68.52%, CER 54.07%, но совпало
  только 17 из 54 эталонных слов — начало речи потеряно.
- original сохранил 39 из 54 эталонных слов, но добавил 36 лишних; WER 94.44%.
- Сильное шумоподавление, dialogue_isolated и both_channels_asr ухудшили
  результат; mild_denoise оказался худшим (WER 122.22%).

Следующий тест: запускать без prompt по умолчанию, с одинаковым временным
диапазоном и точным эталоном для него. Если контекст нужен, отдельно сравнить
короткий список терминов, а не полное предложение.
