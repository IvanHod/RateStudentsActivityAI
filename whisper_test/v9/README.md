# Эксперимент v9: Qwen3-ASR-1.7B

## Цель

Сравнить Qwen3-ASR-1.7B через локальный Ollama API с Whisper на исходном
фрагменте и пяти наиболее сильных вариантах предобработки.

## Набор аудио

1. исходный `chunk_0049_original`;
2. `target_voice_focus`;
3. `target_from_13s`;
4. `target_strong_denoise`;
5. stereo mix L/R `60/40`;
6. `direct_mid`.

## Условия

Бэкенд `ollama`, модель `frozenlab/qwen3-asr:1.7b`, локальный URL
`http://127.0.0.1:11434`, язык `ru`, VAD `0.5 / 100 / 500 / 200`. Для
сопоставимости используются тот же эталон, нормализация, WER и CER, что в
предыдущих версиях.

## Результаты

Артефакты: [`results.csv`](results.csv) и [`details.txt`](details.txt).

| Вариант | WER | CER |
| --- | ---: | ---: |
| `target_voice_focus` | **42.59%** | **30.62%** |
| `target_strong_denoise` | 57.41% | 32.57% |
| исходный WAV | 57.41% | 34.53% |
| stereo mix `60/40` | 59.26% | 36.81% |
| `direct_mid` | 62.96% | 42.02% |
| `target_from_13s` | 100.00% | 100.00% |

Qwen3-ASR-1.7B успешно отвечает через Ollama, но на этом фрагменте уступает
Whisper `medium + target_voice_focus` (WER 27.78%). После удаления служебной
ASR-обёртки из ответа модель всё равно не распознала «неявное преобразование
типов»: лучший вариант дал «я на преподавании».
