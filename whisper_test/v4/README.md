# Эксперимент v4: подбор чувствительности и padding VAD

## Цель

В v3 мягкий VAD улучшил WER исходной записи с 100.00% до 33.33%. Однако этот
вывод получен на одном размеченном фрагменте и одной комбинации параметров.
В v4 проверяется, как на результат влияют чувствительность VAD и запас аудио
у границ речевых сегментов.

## Гипотеза

Более низкий `threshold` и больший `speech_pad_ms` должны сохранять короткие
реплики и начала слов. Но чрезмерная чувствительность или padding могут снова
добавить шум, паузы и лишние слова. Поэтому параметр выбирается не только по
WER, но и по количеству вставок и ручной проверке транскрипции.

## Сетка параметров

Фиксированные параметры:

- `min_speech_duration_ms=100` — не отбрасывать короткие реплики;
- `min_silence_duration_ms=500` — не разрывать естественные короткие паузы;
- Whisper `medium`, язык `ru`, `beam_size=5`, температура `0.0`;
- `initial_prompt` отключён.

Перебираемые параметры:

| `threshold` | `speech_pad_ms` |
| --- | --- |
| 0.4, 0.5, 0.6 | 200, 400, 600 |

Всего девять независимых запусков. По умолчанию они используют тот же набор
из семи вариантов аудио, что и v3. Можно передать в скрипт другие файлы или
папки — это нужно для подтверждения результата на нескольких размеченных
фрагментах.

## Запуск

Из корня репозитория:

```bash
uv run python whisper_test/v4/run_vad_grid.py
```

Чтобы проверить несколько размеченных записей, перечислите их после команды:

```bash
uv run python whisper_test/v4/run_vad_grid.py path/to/lecture_1.wav path/to/lecture_2.wav
```

Результаты каждого сочетания записываются в `results/` отдельными CSV и TXT.
`results/summary.csv` содержит лучший аудиовариант, WER, CER, число вставок и
статистику VAD для каждой из девяти конфигураций.

## Критерий выбора

Выбирать следует не просто наименьший WER, а комбинацию, которая:

1. имеет низкий WER и CER;
2. не создаёт большого числа вставок;
3. сохраняет первые слова и короткие реплики при прослушивании;
4. сохраняет качество на нескольких независимых записях.

Текущий рабочий профиль в `compare_noize_removing.py` изменён на настройки,
лучшие в v3: `threshold=0.5`, `min_speech=100 мс`, `min_silence=500 мс`,
`speech_pad=400 мс`. v4 либо подтвердит его, либо даст основание выбрать
другую комбинацию.
