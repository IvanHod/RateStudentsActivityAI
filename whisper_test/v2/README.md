# Эксперимент v2: базовое распознавание без prompt

## Цель

Проверить, как варианты предобработки одного фрагмента лекции влияют на
распознавание русской речи в Whisper, исключив искажение от `initial_prompt`,
обнаруженное в v1.

## Данные и методика

- Эталон содержит 54 слова и начинается с «Да. Не факт…».
- Сравнивались оригинал и шесть вариантов обработки аудио.
- Использовались OpenAI Whisper `medium`, язык `ru`, `beam_size=5` и
  температурный режим `0.0`.
- Оценивался весь файл; VAD в этой версии не применялся.
- Метрики: WER — доля ошибок на уровне слов, CER — на уровне символов.

Полные транскрипции и выравнивание ошибок находятся в
[`whisper_comparison_details.txt`](whisper_comparison_details.txt), сводка — в
[`whisper_comparison.csv`](whisper_comparison.csv).

## Результат

Лучший WER показал `chunk_0049_target_voice_focus.wav`: **59.26%**
(32 ошибки из 54 слов). `target_strong_denoise` близок к нему с WER **61.11%**.
У `target_spectral_subtraction` лучше CER — **44.95%**, однако 27 вставок
ухудшили WER до **74.07%**.

Оригинальный файл имеет WER **100.00%**: из 54 эталонных слов распознано 38,
но добавлено 38 лишних слов. Наилучшие по WER варианты также пропускают начало
эталонной фразы и повторяют «Да», поэтому одной WER недостаточно для выбора
препроцессинга.

## Вывод и следующий шаг

Шумоподавление улучшает результат относительно оригинала, но отдельные методы
теряют короткие фрагменты речи и провоцируют повторения. В следующей версии
нужно проверить VAD с мягкими настройками и сравнить его с этим запуском без
VAD на том же наборе файлов.
