# Эксперимент v7: stereo mix и чувствительность VAD

## Цель

Проверить две гипотезы, оставшиеся после v6:

1. Целевая речь находится преимущественно в левом канале, но небольшая доля
   правого канала может помогать downmix.
2. Для прямого извлечения VAD может отбрасывать тихие слова: в v6 он оставил
   около 19 с речи, против 29.28 с у `target_voice_focus`.

## Этап 1: stereo mix

Из lossless stereo-фрагмента v6 созданы варианты с весами L/R: `100/0`,
`80/20`, `70/30`, `60/40`, `50/50`. Они оцениваются с текущим профилем VAD:
`threshold=0.5`, `min_speech=100 мс`, `min_silence=500 мс`, `padding=200 мс`.

## Этап 2: VAD

Для лучшего stereo mix будет выполнена сетка:

- `threshold`: 0.3, 0.4, 0.5;
- `speech_pad_ms`: 200, 400;
- `min_speech_duration_ms`: 50;
- `min_silence_duration_ms`: 500.

Нужно оценивать WER вместе с числом вставок и длительностью речи VAD. Более
длинный VAD-вход не считается улучшением, если он вызывает повторы Whisper.

## Результаты этапа 1

Полные данные: [`stage1_stereo_mix.csv`](stage1_stereo_mix.csv) и
[`stage1_stereo_mix.txt`](stage1_stereo_mix.txt).

| Mix L/R | WER | CER | Точных слов |
| --- | ---: | ---: | ---: |
| `60/40` | **33.33%** | **21.50%** | 38 |
| `70/30` | 35.19% | 22.80% | 37 |
| `50/50` | 38.89% | 24.10% | 34 |
| `80/20` | 38.89% | 29.32% | 35 |
| `100/0` | 44.44% | 29.97% | 32 |
| `target_voice_focus` (контроль) | **27.78%** | **16.94%** | 41 |

Гипотеза о полезной примеси правого канала подтвердилась: `60/40` лучше
обычного `50/50` на 5.56 п.п. WER. Однако он не превзошёл `target_voice_focus`.

Полные данные по шести точкам: [`vad_grid`](vad_grid).

| Threshold | Padding | WER | Вставки | Речи VAD |
| ---: | ---: | ---: | ---: | ---: |
| 0.3 | 200 мс | 44.44% | 1 | 21.01 с |
| 0.3 | 400 мс | 37.04% | 2 | 25.31 с |

Лучший новый VAD-профиль для `60/40` — `threshold=0.4`,
`min_speech=50 мс`, `min_silence=500 мс`, `padding=400 мс`. Он сравнялся по
WER с текущим профилем `0.5 / 100 / 500 / 200`, но не улучшил контрольный
`target_voice_focus`.

## Вывод

Для прямого stereo-источника полезно использовать mix L/R `60/40`; VAD требует
отдельной настройки для такого входа. Но основную конфигурацию не следует
менять: лучшая связка остаётся `target_voice_focus` с VAD `0.5 / 100 / 500 /
200`. Следующая проверяемая гипотеза для v8 — сохранить короткие паузы между
VAD-сегментами вместо их склейки встык.
