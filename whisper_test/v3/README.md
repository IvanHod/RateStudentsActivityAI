# Эксперимент v3: сравнение VAD с запуском без VAD

## Цель

Проверить, уменьшает ли детектор речевой активности (Silero VAD) лишние
фрагменты и повторы Whisper, не теряя начало речи.

## Набор и общие условия

Сравниваются семь одинаковых аудиовариантов: исходная запись,
`target_continuous`, `target_from_13s`, `target_spectral_subtraction`,
`target_strong_denoise`, `target_voice_focus` и `whisper_enhanced`.

Во всех запусках: OpenAI Whisper `medium`, язык `ru`, `beam_size=5`,
температура `0.0`, распознавание всего файла и отключённый `initial_prompt`.
Эталон содержит 54 слова. Метрики WER и CER считаются после одинаковой
нормализации текста.

## Запуск без VAD

Артефакты: [`without_vad.csv`](without_vad.csv) и
[`without_vad.txt`](without_vad.txt).

VAD отключён. Лучший WER — **59.26%** у `target_voice_focus`; далее
`target_strong_denoise` с **61.11%**. Общая проблема — пропуск начала фразы и
повторы «Да» у лучших по WER вариантов. Поэтому требуется отдельная проверка
VAD, а не вывод о качестве лишь по лучшей строке таблицы.

## Запуск с мягким VAD

Артефакты: [`with_vad_soft.csv`](with_vad_soft.csv) и
[`with_vad_soft.txt`](with_vad_soft.txt).

Параметры выбраны для сохранения короткой речи и границ слов:

- `threshold=0.5`;
- `min_speech_duration_ms=100`;
- `min_silence_duration_ms=500`;
- `speech_pad_ms=400`.

Для каждой записи CSV содержит число обнаруженных сегментов и суммарную
длительность речи. Результат следует сопоставлять с вариантом без VAD по WER,
CER, числу вставок и вручную по началу транскрипции.

## Результат сравнения

Мягкий VAD заметно улучшил распознавание и сохранил начало эталонной фразы.
Лучший результат дал исходный файл: **WER 33.33%**, **CER 22.80%**, 38 точных
совпадений из 54 слов, 2 вставки. VAD выделил в нём 9 сегментов общей
длительностью 22.53 с. Для сравнения, без VAD у исходного файла WER был
**100.00%**.

`target_voice_focus` стал вторым: **WER 35.19%**, но содержит 7 вставок.
У `target_from_13s` WER **44.44%**. Сильное шумоподавление и
`target_continuous` с VAD неудачны: WER соответственно **79.63%** и
**98.15%**, главным образом из-за повторов и вставок.

## Вывод

Для этого фрагмента следует использовать исходное аудио вместе с мягким VAD:
оно лучше всех обработанных вариантов по WER и хорошо ограничивает
галлюцинированные фрагменты. Результат относится к одному размеченному
фрагменту; перед переносом настройки в основной конвейер её нужно подтвердить
на нескольких записях с разными уровнями шума.
