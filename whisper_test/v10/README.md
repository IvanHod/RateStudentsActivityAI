# Эксперимент v10: Qwen3-ASR-0.6B

## Цель

Сравнить компактную Qwen3-ASR-0.6B с Qwen3-ASR-1.7B на идентичном наборе
аудио и неизменных условиях оценки.

## Набор и условия

Используются исходный `chunk_0049_original`, `target_voice_focus`,
`target_from_13s`, `target_strong_denoise`, stereo mix L/R `60/40` и
`direct_mid`. Бэкенд `ollama`, модель `frozenlab/qwen3-asr:0.6b`, локальный
URL `http://127.0.0.1:11434`, язык `ru`, VAD `0.5 / 100 / 500 / 200`.

Метрики WER/CER и эталон совпадают с v9, поэтому результат покажет реальный
компромисс качества и скорости между двумя размерами Qwen3-ASR.

## Результаты

Артефакты: [`results.csv`](results.csv) и [`details.txt`](details.txt).

| Вариант | WER | CER |
| --- | ---: | ---: |
| `target_strong_denoise` | **64.81%** | **40.39%** |
| исходный WAV | 64.81% | 45.60% |
| stereo mix `60/40` | 64.81% | 48.86% |
| `target_voice_focus` | 70.37% | 47.56% |
| `target_from_13s` | 70.37% | 51.47% |
| `direct_mid` | 75.93% | 45.28% |

Qwen3-ASR-0.6B работает, но на всех вариантах заметно хуже 1.7B: лучший WER
хуже на 22.22 п.п. Поэтому 0.6B не подходит как компромисс качества для этой
задачи и не должен заменять Whisper в основном конвейере.
